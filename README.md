# 📄 PDF変換

写真・Word・Excel・PowerPoint・テキストなどを、ブラウザだけで PDF にする Web アプリです。
インストール・アカウント登録は不要で、Mac・Windows・スマホのブラウザで開くだけで使えます。

**ファイルはインターネットに送信されません。** 変換はすべて、使っている端末のブラウザの中で行います。

## できること

- **いろいろな形式を PDF に** — 画像・PDF・Word・Excel・PowerPoint・テキスト・Markdown・CSV・Webページ
- **まとめて変換** — ファイルをいくつでも一度に選べます
- **1つの PDF にまとめる** — 選んだ順番どおりにページをつなげます（写真10枚 → PDF 1冊、など）
- **別々の PDF にする** — ファイルごとに PDF を作り、ZIP 1つにまとめてダウンロードできます
- **並べ替え** — ↑↓ボタンで順番を変えられます。「名前順」なら `IMG_2` が `IMG_10` より前になります
- **スマホで保存** — iPhone では「共有・『ファイル』に保存」から、ファイルアプリや LINE などに送れます

## 使い方

1. 「＋ ファイルを選ぶ」を押して、PDF にしたいファイルを選びます（パソコンではドラッグ＆ドロップでも追加できます）
2. 必要なら ↑↓ で順番を並べ替えます
3. 「1つのPDFにまとめる」か「ファイルごとに別々のPDFにする」を選びます
4. 「PDFにする」を押し、終わったら「ダウンロード」を押します

変換できないファイルがあっても、ほかのファイルの変換は続けます。最後に「変換できなかったファイル」とその理由が表示されます。

## 形式ごとの仕上がり

| 形式 | 仕上がり |
|---|---|
| 画像（JPG・PNG・GIF・WebP・HEIC） | 1枚 = 1ページ。横長の写真は横向きのページになります。iPhone の写真の向きも正しく直ります |
| PDF | そのままつなげます（画質は変わりません） |
| Word（.docx） | 文字・見出し・表・画像・箇条書きが入ります |
| Excel（.xlsx / .xls）・CSV | シートごとに表になります。横に広い表は横向き・縮小し、それでも入らなければ横にもページを分けます。非表示のシートは出しません |
| PowerPoint（.pptx） | 1スライド = 1ページ。文字・画像・図形・表を位置どおりに並べます。非表示のスライドは出しません |
| テキスト（.txt）・Markdown（.md） | A4 の文書になります。Windows で作った Shift_JIS のファイルも文字化けしません |
| Webページ（.html） | 保存したページを A4 にします |

## ⚠️ できないこと・注意点

- **できた PDF の文字は選択・検索できません。** ページを画像として作っているためです（どの端末でも同じ見た目になり、文字化けもしません）。元から PDF のファイルは例外で、そのままつなげます
- **Word・PowerPoint は「だいたい同じ見た目」です。** ブラウザだけで完全に同じにはできません
  - Word：ヘッダー・フッター、細かい配置、元のページ区切りの位置は再現されません
  - PowerPoint：グラフ・SmartArt・アニメーション・凝った装飾は表示されません（グラフの場所には「表示できません」と出ます）。フォントは端末にあるものに置き換わります
  - 見た目を完全に保ちたいときは、Word・PowerPoint の「ファイル → エクスポート（書き出し）→ PDF」を使ってください
- **使えない形式**
  - 古い形式の `.doc` / `.ppt` → Word・PowerPoint で開いて `.docx` / `.pptx` に保存し直してください
  - Mac の Pages・Numbers・Keynote → アプリの「ファイル → 書き出す → PDF」でそのまま PDF にできます
  - パスワード付きのファイル
- **Webページの外部画像は入りません。** 外部への通信をすべて禁止しているためです
- 1ファイルあたり 300 ページまでです

## スマホで使う（ホーム画面に追加）

- **iPhone（Safari）** — 共有ボタン（□に↑）→「ホーム画面に追加」
- **Android（Chrome）** — 右上の ︙ →「ホーム画面に追加」

## ローカルで動かす

```bash
cd 他人が使うツール３
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。
（`index.html` をダブルクリックして直接開くと、ブラウザの安全機能で部品が読み込めないことがあります。必ずサーバー経由で開いてください。）

## GitHub Pages で公開する

```bash
cd 他人が使うツール３
git init
git add -A
git commit -m "PDF変換アプリ 初版"
gh repo create <リポジトリ名> --public --source=. --push
```

その後、GitHub のリポジトリページで
**Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`**
を選んで Save します。数分後に次の URL で公開されます。

```
https://<ユーザー名>.github.io/<リポジトリ名>/
```

公開されるのはアプリのプログラムだけです。利用者が選んだファイルが GitHub に送られることはありません。

## ファイルが外部に送られない仕組み

- 変換処理はすべてブラウザの中（JavaScript）で行い、サーバーは使いません
- 部品（ライブラリ）は `lib/` に同梱しており、外部のサイトから読み込みません
- `index.html` の Content-Security-Policy で、**アプリ自身のサーバー以外への通信をブラウザが禁止**します。仮にプログラムに誤りがあっても、外部には送れません

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面の構造と、外部通信を禁止する設定 |
| `style.css` | 見た目（スマホ縦画面が基準、ダークモード対応） |
| `app.js` | ファイルの追加・並べ替え・変換の実行・ダウンロード |
| `converters.js` | 形式の判定と、形式ごとの変換（ページ割り・PowerPoint の読み取りなど） |
| `pdf.js` | 変換したページを1冊の PDF に組み立てる |
| `lib/` | 同梱ライブラリ（下記）。その形式を変換するときだけ読み込みます。ライセンス文は `lib/LICENSES.txt` |
| `test.mjs` | 計算部分のテスト。`node test.mjs` で実行（51項目） |
| `samples/` | 動作確認用のサンプルファイル（各形式） |
| `manifest.webmanifest`, `icon-*.png` | ホーム画面に追加したときの名前とアイコン |
