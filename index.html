    変換できなかったファイル

      使えるファイルと注意点
      • 画像（JPG・PNG・HEIC など）… 1枚が1ページになります
      • PDF … そのままつなげます（複数のPDFを1つにまとめられます）
      • Word（.docx）… 文字・見出し・表・画像が入ります。ヘッダー・フッターや細かい配置は再現されません
      • Excel（.xlsx / .xls）・CSV … シートごとに表になります。横に広い表は横向き・縮小します
      • PowerPoint（.pptx）… 1スライドが1ページです。文字・画像・表は入りますが、グラフや SmartArt は表示されません
      • テキスト・Markdown・Webページ（.txt / .md / .html）

      できたPDFは「ページの写真」のような作りです。PDFの中の文字は選択・検索できません。

      古い形式の .doc / .ppt は使えません。Word・PowerPoint で .docx / .pptx に保存し直してください。

      🔒 ファイルはこの端末の中だけで変換され、インターネットには送信されません。
